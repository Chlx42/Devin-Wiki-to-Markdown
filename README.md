# Devin-Wiki to Markdown

Convert DeepWiki & Devin Wiki pages into clean Markdown files and export them as ZIP packages.

---

## 🚀 Install

👉 **One-click install (Tampermonkey required):**
https://raw.githubusercontent.com/Chlx42/Devin-Wiki-to-Markdown/main/devin-wiki-md.user.js

---

## ✨ Features

* 📄 Export Wiki pages to Markdown
* 📦 Batch download multiple pages
* 🗜️ Automatically package files as ZIP
* 📊 Mermaid diagram support

---

## 📦 Requirements

* Install Tampermonkey in your browser

---

## 🧭 Usage

1. Open a supported Wiki page (DeepWiki / Devin)
2. Trigger the script from the menu
3. Export content as Markdown or ZIP
