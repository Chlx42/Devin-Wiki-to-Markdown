# Devin-Wiki to Markdown

Convert DeepWiki & Devin Wiki pages to Markdown and export as ZIP.

## 🚀 Install

👉 Click to install:
https://raw.githubusercontent.com/Chlx42/Devin-Wiki-to-Markdown/main/devin-wiki-md.user.js

## ✨ Features
- Export wiki to Markdown
- Batch download
- ZIP packaging

## 📦 Requirements
- Tampermonkey
